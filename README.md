# Subtle

Sitio estático de una sola página. No necesita instalar dependencias ni compilarse: editá `index.html` y guardá los cambios en la rama `main`. El logo está en `vitrail-logo.png`; reemplazá también ese archivo si querés actualizarlo.

## Sitio publicado

[https://julianmmw.github.io/subtle-recording-space/](https://julianmmw.github.io/subtle-recording-space/)

GitHub Pages publica automáticamente el contenido de `main` desde la carpeta raíz. Para actualizar el sitio, editá `index.html` y, si corresponde, reemplazá `vitrail-logo.png`; confirmá los cambios y esperá a que termine el despliegue.

No se incluyeron fotos del espacio. Cuando estén disponibles, se pueden agregar reemplazando o complementando el diseño abstracto.
